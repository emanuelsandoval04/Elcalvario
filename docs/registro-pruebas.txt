 1. SEGURIDAD E INYECCION DE DATOS
---------------------------------------------------------------------
 [SQL]  Inyeccion SQL
        Proteccion: las ~270 consultas usan parametros (?) de mysql2;
        el dato del usuario nunca se pega dentro del SQL.
 [XSS]  Inyeccion de scripts (HTML/JS)
        Proteccion: React escapa todo el texto; 0 usos de innerHTML.
        Prueba: CSP de produccion verificada (script-src-attr 'none',
        object-src 'none', sin 'unsafe-inline')            -> PASS
 [CSRF] Peticiones desde otro sitio (Origin: untrusted.invalid)
        crear cuenta / editar perfil / subir foto / borrar  -> 403 PASS
 [AUTH] Sin sesion                                         -> 401 PASS
        Rol sin permiso                                    -> 403 PASS
        Crear rol igual o superior al propio               -> 403 PASS
        Registro publico deshabilitado                     -> 403 PASS
 [FUERZA BRUTA] 16 intentos de login desde 16 IP distintas
        intento 16 bloqueado por cuenta                    -> 429 PASS
        Limite general por IP / exportaciones              -> 429 PASS
 [PAYLOAD] Foto de 350 KB falsa (base64 basura)            -> 413 PASS
        Cuerpo comprimido gzip no permitido                -> 415 PASS
        JSON mal formado                                   -> 400 PASS
 [SESION] Inactiva 31 min                                  -> 401 PASS
        Sesion revocada desde otro dispositivo             -> 401 PASS
        Cambio de contrasena invalida sesiones viejas      -> 401 PASS
 [DATOS] Auditoria no guarda contrasenas                   -> PASS
        Listado de sesiones no expone el token             -> PASS
        Recuperacion: responde igual exista o no el correo -> PASS
        Enlace de recuperacion de un solo uso, 15 min      -> PASS
